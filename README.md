In this project, we built a decision tree model as well as a random forest model using the Telco churn dataset (cleanup was required). 

After splitting the dataset into training and test sets, the model was trained/fit and evaluated using standard performance metrics.

These models were then compared to the previously built logistic regression model that was built using this dataset (see under Repositories) to draw insights on which were best performing.

Feature importance was also analyzed and visualized to understand which features were most significant to the model and predictive of customer churn.
